# Pixelify Sans

Tipografía pixelada de Stefie Justprince, incluida sin modificar.
No es la tipografía oficial de Minecraft.

Origen: https://github.com/google/fonts/tree/main/ofl/pixelifysans
Archivo original: `PixelifySans[wght].ttf`; copia local: `PixelifySans.ttf`.
Licencia SIL Open Font License 1.1, incluida en `OFL.txt`.
Copyright 2021 The Pixelify Sans Project Authors.

Se registra únicamente dentro de la aplicación con Qt, una sola vez por proceso.
No se instala en Windows ni necesita Internet al ejecutar la mascota.
Si falta o no se puede cargar, se usa Consolas como respaldo.
